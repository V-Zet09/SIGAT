## 📌 Descripción
**SIGAT** es un sistema web desarrollado para el **Honorable Ayuntamiento de Tlapehuala**, con el objetivo de **agilizar y centralizar la elaboración de informes de gobierno**, permitiendo una gestión más eficiente de la información administrativa.

El sistema digitaliza procesos que anteriormente se realizaban de forma manual, mejorando la organización, el seguimiento de actividades y la generación de reportes institucionales.

---

## 🧑‍💼 Mi rol en el proyecto
- Desarrollo backend utilizando **Laravel (PHP)**
- Diseño y administración de **bases de datos relacionales**
- Implementación de **roles y permisos de usuario**
- Desarrollo de funcionalidades **CRUD**
- Optimización de **consultas SQL**
- Control de versiones con **Git/GitHub**

## ⚙️ Funcionalidades principales
- Gestión de actividades institucionales
- Registro y seguimiento de información administrativa
- Generación de informes de gobierno
- Control de usuarios con roles y permisos
- Validación de datos y manejo de errores
- Interfaz web responsiva

## 🛠️ Instalación

```bash
git clone https://github.com/V-Zet09/SIGAT.git
cd SIGAT
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
npm run dev
